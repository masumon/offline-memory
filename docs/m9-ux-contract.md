# M9 UX Contract

## Navigation

Primary workflows must be reachable without relying on hidden routes. Secondary/system tools belong outside the primary task/memory actions.

## Forms

Create and edit forms must distinguish required input, invalid input, saving, saved, and failure states. Destructive actions must be visually and semantically distinct from primary save actions.

## Lists

Lists must provide meaningful loading and empty states. Search/filter results must navigate to the correct entity detail surface. Mutations must refresh or reconcile visible state rather than leaving stale rows.

## Offline-first

User-facing copy must not imply cloud synchronization. Local data availability and local-only behavior should be explicit where useful.

## Accessibility

Interactive controls require useful labels and state semantics. Selection controls expose selected state. Destructive actions expose clear labels. Touch targets remain usable on mobile.

## Consistency

Use the existing application visual language rather than introducing a parallel component or styling system.
