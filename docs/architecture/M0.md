# M0 — Project Bootstrap

## Goal

Establish a stable Android-first foundation for a fully offline personal memory and productivity application.

## Runtime boundaries

- UI must not access SQLite directly.
- Application services own business operations.
- Repositories own persistence access.
- Local intelligence will issue validated application actions through the orchestrator.
- No cloud backend is required for core functionality.
- No external LLM/API is part of the product architecture.

## Local data

SQLite is the source of truth. WAL mode is enabled and foreign-key enforcement is enabled. Database changes are versioned through migrations.

## Local notifications

Android notification channels are initialized locally. Scheduling logic will be added in the reminder phase.

## AI boundary

Future local AI modules will be isolated under `src/ai/`:

- normalization
- language detection
- tokenization
- intent classification
- entity extraction
- date/time parsing
- context resolution
- rule evaluation
- planning
- orchestration

No model or network service is required for the first implementation of these capabilities.

## Verification

The local environment should run:

```bash
npm install
npm run typecheck
npm run lint
npm test
npx expo start
```

A native Android build should later be validated with:

```bash
npx expo run:android
```
